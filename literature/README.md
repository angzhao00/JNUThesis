# 文献材料目录

本目录是硕士学位论文的辅助资料区，不代表论文要写成一篇独立综述。

所有拟引用文献必须真实存在、可查询并完成元数据核验。遇到付费全文时，保存题名、DOI、数据库和直达链接，由用户通过学校图书馆的合法登录会话获取；不收集或保存用户密码、验证码和令牌。

当前已形成85篇去重后的工作文献库，其中中文文献20篇、中文硕士/博士学位论文5篇；按既定“2021年至检索日”口径统计，近年文献55篇，占64.7%。第一、二章合计已引用全部85篇，正式论文文件尚未覆盖，等待用户审阅。

本目录用于保存：

- 检索式、检索日期、数据库和筛选日志；
- 去重后的文献元数据与BibTeX核验记录；
- 合法获取的PDF、全文链接或访问说明；
- 阅读卡片、主题分类、国内外研究现状证据表；
- 候选创新点的查新和相似工作对照。

检索筛选流程图和论文问题—证据关系图默认只作内部审计，不放入正式论文。

整篇论文的唯一总任务说明见`plans/MASTER_THESIS_WRITING_PLAN.md`；当前文献汇总见`reference_collection_report.md`，新增10篇的逐条核验记录见`reference_addition_log.csv`。

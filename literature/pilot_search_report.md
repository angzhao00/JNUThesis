## 2. 初步证据判断

### 2.1 可直接支撑论文的证据

- φ-OTDR/DAS的核心信号模型、相干探测和相位恢复已有成熟论文与综述；
- I/Q幅度失衡、激光频漂、中频滤波参数和偏振/相干衰落对解调性能的影响均有直接研究；
- 近期论文已把频率漂移、实时相位解调和衰落抑制作为独立问题处理，可用于第一章梳理技术进展，也可为第二章建立误差模型。

### 2.2 只能作为机理支撑的证据

- 已核验的SOA论文能够证明载流子瞬态、增益变化和折射率/相位变化之间存在耦合，并可产生动态频率啁啾；
- 这些论文主要来自光通信、波长转换或SOA器件表征，不能直接证明用户DAS系统中观察到的拍频偏移必然由同一机制造成；
- 因此第一、二章应写成“机理上可能影响相位和频率”，第三章仍需用用户实验完成DAS链路中的直接验证。

## 3. 当前缺口

1. AOM射频门控、声场建立时间、同步触发和热稳定性的同行评议论文不足；
2. 直接讨论“LD–SOA作为DAS发射端放大与脉冲器件”的论文数量不足；
3. 已有片上和混合集成DAS询问器可作为用户收发模组的外部对比，但其集成平台、器件功能和系统边界与用户的分立器件封装集成不同，不能直接等同；
4. 小样本阶段中文文献覆盖不足；该缺口已在后续批量检索中补足，当前工作库含20篇中文文献；
5. 19篇种子文献中仍有若干只有出版社摘要或元数据，进入核心引用前需要获取全文并记录页码、图表或章节。

## 4. 下一轮检索重点

1. 以已核验综述和代表作执行前向、后向引文追踪；
2. 专项检索AOM开关延迟、声学渡越时间、RF门控和同步控制；
3. 扩展SOA脉冲放大、消光比、ASE、增益饱和、载流子恢复和瞬态啁啾文献；
4. 检索compact/interrogator/module/integrated photonics等词，但只保留与DAS收发链路有实质可比性的工作；
5. 建立中文检索式并利用学校数据库权限补足国内论文；
6. 后续已完成扩展、筛选和去重，形成85篇正式工作库，其中新增5篇中文硕博学位论文和5篇近年中文期刊论文。

## 5. 写作边界

- 第一章可以先依据已核验种子文献建立段落级论证结构，但完整正文需等待主题分布基本平衡；
- 第二章可以优先撰写φ-OTDR、外差探测、数字下变频和差分相位等成熟原理；
- SOA瞬态啁啾部分只能陈述通用器件机理与待验证影响，不提前把用户实验机理写成定论；
- 第二章不设置“收发模组原理”，集成模组仅作为第三章的结构设计与性能对比对象。

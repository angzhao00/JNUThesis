# 第一章论证提纲

## 1.1 研究背景与意义

- 分布式光纤振动传感以光纤本身形成连续传感阵列，具有长距离、高密度和抗电磁干扰等特点；
- φ-OTDR通过相干瑞利后向散射实现扰动定位与动态相位恢复，是DAS的重要技术路线；
- 工程应用不仅取决于测距和空间分辨率，还受发射脉冲、相干接收、偏振衰落、拍频稳定性和数字解调共同制约；
- 本文关注的核心问题是：集成LD–SOA发射链路、收发光路集成和接收解调参数如何共同影响系统性能。

**首批证据：** `posey2000strain`、`lu2010distributed`、`masoudi2016review`、`muanenda2018advances`、`he2021review`。

## 1.2 国内外研究现状

### φ-OTDR/DAS技术演进

- 从相干瑞利散射应变感知、外差φ-OTDR，到数字相干检测、脉冲编码和实时解调；
- 比较不同工作中的传感距离、空间分辨率、频率响应、应变灵敏度和系统复杂度；
- 不在实验条件不同的情况下直接排列“最高性能”。

**首批证据：** `posey2000strain`、`lu2010distributed`、`pan2011phase`、`liokumovich2015fundamentals`、`wang2019pulsecoding`、`he2021review`。

### LD–SOA脉冲发射与AOM移频

- 先说明SOA的增益、载流子恢复、ASE、增益饱和和相位—幅度耦合；
- 再说明AOM的固定移频、声光作用建立时间和门控窗口；
- 明确区分“SOA器件机理论文”和“SOA直接用于DAS的系统论文”；
- 只把SOA载流子动态导致频率变化写成有理论依据的可能影响，用户系统中的拍频偏移仍需第三章实验验证。

**首批证据：** `cao2002characterization`、`zilkie2008linewidth`、`matsuura2015chirp`、`yang2021carrier`、`johnson1977aom`。

### 收发系统小型化与模块级集成

- 传统分立光路便于器件替换和单点调试，但连接点多、体积大，易受插损、偏振态、机械扰动和接口重复性的影响；
- 用户完成的DAS收发集成光模组，是将集成LD–SOA光源、AOM、BPD、PBS、2×2耦合器和环形器进行模块级光路集成；
- 文献中的片上调制器、硅光集成DAS询问器和混合集成询问器用于说明小型化趋势，但不能与用户的器件封装集成混称为同一种集成；
- 第一章只评述技术路线，具体结构和分立—集成性能对比放入第三章。

**建议的分立—集成对比维度：**

1. 光学：插入损耗、输出峰值功率、脉冲完整性、消光比、拍频中心与谱宽；
2. 接收：BPD输出幅度、共模抑制、噪声底、双偏振幅值一致性；
3. 传感：SNR、相位噪声、振动频率和定位误差、衰落概率；
4. 工程：体积、功耗、接口数量、装调时间、长期漂移和重复装插一致性。

**首批证据：** `cheng2023onchip`、`jin2024integrated`、`jin2026hybrid`。

### 相干接收、偏振分集与数字解调

- 外差接收和I/Q解调能够恢复复振幅，但会受I/Q不平衡、实际拍频与数字本振失配、滤波器带宽和偏振/相干衰落影响；
- 研究进展包括偏振分集、邻域统计、频率分集、频漂补偿、准匹配IF滤波和实时解调；
- 本文只将常规双偏振合成和经验参数调整写为“接收与解调优化”，不列为独立算法创新。

**首批证据：** `fu2018iq`、`dorize2018polarization`、`tu2020fading`、`zhong2021frequency`、`zhang2025if`、`qian2025drift`、`liu2025realtime`、`hu2025realtime`。

## 1.3 本文主要内容与技术路线

- 第2章建立φ-OTDR、LD–SOA脉冲发射、AOM移频、外差探测和数字解调模型；
- 第3章研究LD–SOA发射链路、DAS收发集成光模组，并完成分立与集成系统性能对比；
- 第4章完成接收链路、偏振合成、数字解调参数优化和振动实验验证；
- 第5章总结已由数据支撑的结论与局限。

## 1.4 本文主要工作与创新点

- 候选研究贡献一：集成LD–SOA脉冲发射及其瞬态频率特性对外差解调的影响；
- 候选研究贡献二：DAS收发光路的模块级集成以及相对于分立光路的系统性能评估；
- 接收与解调部分暂定为系统优化，不列为独立算法创新；
- 最终措辞需在全文检索、分立—集成对照实验和数据审计完成后定稿。

\chapter{结论与展望}

\section{全文总结}

\begin{writingplan}
  \item 第一段概括研究对象、问题和技术路线，突出无EDFA的ECL--SOA发射链路、SOA--AOM--DAQ协同门控及DAS一体化收发模组两条贡献主线。
  \item 第二部分按第三章结果总结SOA输出功率/脉冲/消光、拍频影响、协同门控、模组设计及损耗、隔离、串扰、通道一致性和硬件稳定性，所有数值对应正式图表。
  \item 第三部分按第四章结果总结统一解调条件下的振动定位、频率与波形恢复、D/M端到端对比、重复性和实验时长内稳定性。
  \item 单列研究限制：模组级而非单片集成、器件参数和样本量范围、分立/模组未能完全一致的条件、测量不确定度及SOA动态机理证据边界。
  \item 最终贡献表述必须与第1.4节逐条一致，并能由正文图表和实验直接支持；删去未完成实验对应的结论，不以计划或专利方案代替验证结果。
\end{writingplan}

\section{研究展望}

\begin{writingplan}
  \item 无AOM方案：在当前AOM固定移频系统完成验证的基础上，讨论利用SOA动态或其他方案减少移频器件的可能性，并作为后续研究方向。
  \item 控制与解调：展望拍频中心自动跟踪、自适应参数和更完善的偏振处理，在本文统一数字解调流程的基础上讨论改进空间。
  \item 集成与封装：提出更高集成度、低损耗连接、热设计、射频/模拟隔离和标准化接口的改进方向，并区分已实现层级与未来设想。
  \item 系统验证：扩展至更长光纤、更宽振动频带、更多扰动类型、复杂环境和现场长期运行，建立更大样本的可靠性与不确定度评价。
  \item 每项展望均由正文已暴露的具体限制自然引出，与全文总结区分，并以具备实施基础的性能方向为限。
\end{writingplan}
